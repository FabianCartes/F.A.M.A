## Contract decisions

- New tables do not alter legacy dataset/audio tables. Managed storage is `backend/data/dataset-imports` (within Compose's persistent data bind), outside `data/raw`. No fake `gs://` local references, training registry entries or legacy walker exposure. New authenticated list/download interfaces preserve the legacy interfaces unchanged.
- Linux filesystem lock serializes managed mutations across processes sharing the same root; database journal plus exclusive per-import files reconciles publication. Multi-host deployments require one shared lock-capable POSIX volume; unsupported roots fail closed. No promise of distributed locks or filesystem/database atomicity.
- Conservative initial configurable ceilings, not a capacity claim: ZIP 64 MiB, actual expanded 256 MiB, 2,000 entries, depth 12, path 240 UTF-8 bytes, WAV 32 MiB/600 s, validation 60 s, disk reserve 512 MiB, four active requests and one active storage mutation, private staging TTL 24 h. ## Future work: Flat-folder ZIP imports and flexible class assignment

Current implementation enforces `<optional_root>/<class_name>/<audio>.wav` (`class_folder_required`) and rejects any non-WAV entry (`wav_only`). To support public datasets and field batches distributed as flat directories (all `.wav` files in a single folder) without losing label integrity, evaluate these extensions in a future iteration:

1. **Manifest-driven labeling (`labels.csv` / `metadata.csv`):** Allow a single validated CSV manifest at the selected root (`filename,class_name`) when `.wav` files reside in a flat folder. Requires bounded CSV parsing, strict 1:1 file-to-row verification during preview, and excluding the CSV from audio storage while recording its provenance in the import manifest.
2. **Single-class batch assignment (UI/API parameter):** Allow the user to specify a target `default_class` in the import preview when uploading a flat ZIP of field recordings belonging to a single species or engine fault state.
3. **Explicit filename-prefix extraction (opt-in preview rule):** Allow a bounded delimiter rule (e.g., prefix before `_` or `-`) only with mandatory preview confirmation of the resulting class set before publication, avoiding silent catalog pollution from inconsistent filenames.

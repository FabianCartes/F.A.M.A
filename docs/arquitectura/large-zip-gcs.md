## Specs

- S1: «Normalización, migración, resúmenes y páginas». «No eliminar información existente sin comprobación y estrategia de recuperación.» Acceptance: explicit, transactional, verified backfill preserving original JSON; normalized indexed per-file/issue records; bounded summaries and stable pages for files/classes/issues. Confirmed seams: authenticated HTTP, explicit migration with synthetic databases, rendered panel. Replace full responses and their frontend consumers together; abort migration on discrepancies without partial activation.
- S2: «Workers, leases, exclusión y admisión». «Impedir que un worker cuyo lease perdió vigencia publique resultados después de ser reemplazado.» Acceptance: persistent jobs and recovery, bounded status, independent leases and short publication exclusion; no long global lock or network transaction.
- S3: «ZIP recibido» «10 GiB»; «Contenido descomprimido por importación» «15 GiB»; «Dataset acumulado» «15 GiB»; «Archivos únicos por dataset» «50.000». «Un GiB equivale a 1024³ bytes.» «Fragmentos de 16 MiB, inicialmente secuenciales.» Acceptance: durable idempotent chunks, ownership, complete-prefix hash verification on resume, exact boundaries and atomic quota/reservation admission. Technical defaults are configurable proposals, not benchmarks.
- S4: «ZIP64 con offset grande y con contadores extendidos.» «El plazo cooperativo existente no equivale a aislamiento del sistema operativo.» Acceptance: bounded EOCD/ZIP64 precheck before entry allocation, real expanded-byte accounting, validated original WAV bytes, killable isolated decoder with resource limits and no network/GCS credentials.
- S5: «Reinicio después de rename y antes de commit.» «Limpieza y reanudación concurrentes.» «Un fallo posterior de limpieza no convierte una importación publicada en fallida.» Acceptance: preserved hash/fsync journal recovery, unique membership, revision/quota recheck, recoverable claimed asynchronous cleanup respecting activity and leases.
- S6: «Se suben WAV individuales, no ZIP intermedios.» «Una revisión parcial no se presentará como completa.» Acceptance: bounded recoverable object batches, verified generations/integrity, immutable complete authorized manifest separate from mutable progress. Manifest preserves canonical paths/classes/provenance/hashes/sizes and supports reconstruction without original ZIP or local membership lists.
- S7: «Exportación que funciona sin ZIP original ni objetos locales.» «Descarga con varios rangos autorizados.» «No utilizar: fetch → response.blob() → URL.createObjectURL() para estas exportaciones.» Acceptance: asynchronous generation-bound verified ZIP64 reconstruction; native authorized resumable download with length/identity/expiry and active-download-safe cleanup; no silent incomplete export or long Next rewrite dependency.
- S8: «No renderizar ni validar toda la colección en una sola respuesta.» «Mantener los documentos del proyecto bajo docs/:» «No crear documentación paralela bajo odd/.» Acceptance: bounded UI and integration checks, operational manuals/limits/manifest/recovery ADRs, index and board updates; report all failed/skipped/pending checks. «Usar datos sintéticos, temporales privados y almacenamiento simulado.» «Operaciones sobre GCS real sin autorización explícita.» remain excluded, as do training, conversions, shared publication and installations by inference.
